# 用户故事

> 基于《绥中项目梳理功能清单》与 PRD，覆盖 8 类用户角色，按优先级 P0 → P1 → P2 排列。

---

## 用户角色

| 角色 | 标识 | 说明 |
|------|------|------|
| 普通游客 | TOURIST | 国内外散客、年卡用户，线上购票/购物/入园 |
| 售票员 | TICKET_SELLER | 窗口售票、取票、退票、办卡 |
| 检票员 | TICKET_CHECKER | 闸机/手持机检票核验 |
| 旅行社操作员 | TRAVEL_AGENT | 批量预订、对账、账户管理 |
| 景区运营管理者 | OPS_MANAGER | 经营大屏、报表、商品/渠道/规则管理 |
| 财务人员 | FINANCE | 清分结算、发票、用友 NC 对接 |
| 商户管理员 | MERCHANT_ADMIN | 商品上架、店铺运营、核销对账 |
| 超级管理员 | SUPER_ADMIN | 系统配置、权限管理、设备监控 |

## P0 — 核心交易链路

### 游客 (TOURIST)

#### US-001 分时预约购票
> **As a** 散客游客
> **I want to** 在线选择日期、时段、票种和人数完成实名购票
> **So that** 无需窗口排队，凭二维码/身份证直接入园

**验收标准：**
- [ ] 支持身份证、护照、港澳台通行证、外国人永久居留证实名购票
- [ ] 每个时段显示剩余库存，售罄自动提示
- [ ] 支持微信、支付宝、银联、外卡、Apple Pay、Google Pay 等支付
- [ ] 支付成功后生成入园二维码和电子票
- [ ] 高峰期可自助改签（自动校验目标时段库存）
- [ ] 限制护照购买老人票和未成年人票

#### US-002 扫码/刷身份证入园
> **As a** 已购票游客
> **I want to** 在闸机扫码或刷身份证快速入园
> **So that** 通行速度不超过 2 秒，避免排队拥堵

**验收标准：**
- [ ] 闸机支持二维码、身份证、护照、港澳台证件核验
- [ ] 通行速率 ≤ 2 秒/人
- [ ] 南北口防重复入园提示
- [ ] 60 岁以上北京老人免换票刷身份证入园

#### US-003 多语言购票
> **As a** 外籍游客
> **I want to** 在我熟悉的语言环境下完成购票
> **So that** 消除语言障碍，自助完成购票流程

**验收标准：**
- [ ] PC 端支持中/英/俄/法/日/西/韩/阿 8 种语言
- [ ] 全站一键语言切换，覆盖购票全流程
- [ ] 支持护照 OCR 自动识别录入证件信息
- [ ] 购票时采集国籍、性别、年龄信息

### 售票员 (TICKET_SELLER)

#### US-004 窗口售票
> **As a** 窗口售票员
> **I want to** 在一体化售票界面完成售票、取票、退票、办卡操作
> **So that** 服务效率最大化，减少游客等待时间

**验收标准：**
- [ ] 支持 F1-F9 快捷键切换常用功能
- [ ] 票型和支付方式自动排序（高频优先）
- [ ] 支持聚合支付：微信、支付宝、银联、银行卡、扫码枪、银行 MIS
- [ ] 售票时自动查询票务状态，防止重复购票
- [ ] 支持售票时采集外宾国籍、性别、年龄
- [ ] 支持部分退款、强制退款（按权限控制）
- [ ] 支持自动查询套票未使用部分，退票明细进入每日结款账单
- [ ] 售票电脑支持浏览器或专用客户端登录

#### US-005 窗口退票
> **As a** 窗口售票员
> **I want to** 为游客办理退票并原路径退款
> **So that** 游客能便捷地取消行程并获得退款

**验收标准：**
- [ ] 支持部分退票（套票中退单个票种）
- [ ] 支持强制退票（管理权限）
- [ ] 退款原路径返回
- [ ] 退票明细计入每日结款账单

### 检票员 (TICKET_CHECKER)

#### US-006 闸机/手持机检票
> **As a** 检票员
> **I want to** 使用闸机或手持机快速验证游客票务信息
> **So that** 高效放行，同时防止无票/假票/重复入园

**验收标准：**
- [ ] 闸机支持二维码、身份证、护照、港澳台证件验票
- [ ] 手持机支持 OCR 识别证件并自动录入查询
- [ ] 通行速率 ≤ 2 秒/人（二维码/身份证），≤ 3 秒/人（人脸）
- [ ] 外籍游客检票时采集客源地、性别、年龄
- [ ] 南北口防重复入园
- [ ] 支持断网情况下纸质票应急检票
- [ ] 前一日网上售票数据预存至闸机/本地服务器，实现离线检票
- [ ] 后台支持录入证件号手动核销
- [ ] 已购纸质票的身份证防重复购票提示

### 旅行社操作员 (TRAVEL_AGENT)

#### US-007 在线预订与批量下单
> **As a** 旅行社操作员
> **I want to** 在线预订门票和组合产品，支持 Excel 批量导入游客信息
> **So that** 高效完成团体订票，减少人工沟通成本

**验收标准：**
- [ ] 支持在线注册、资质审核、在线预订
- [ ] 支持 Excel 批量导入 ≥200 人团队游客信息
- [ ] 支持一人一码/一码多人
- [ ] 支持异常证件自动剔除
- [ ] 区分重点旅行社、普通旅行社、社会团体、周边餐馆分组定价
- [ ] 旅行社端支持小程序、H5、PC 三端
- [ ] 自动审核和人工审核双模式

#### US-008 旅行社付款与对账
> **As a** 旅行社操作员
> **I want to** 通过多种付款方式完成结算并查看对账单
> **So that** 财务管理清晰高效

**验收标准：**
- [ ] 支持扫码付款、对公付款、自动充值扣款、授信额度扣款、现场到付
- [ ] 支持账户余额、流水、在线转账查询
- [ ] 支持销售统计、对账单、订单和支付流水导出
- [ ] 支持协议到期提醒

#### US-009 防倒票与风险控制
> **As a** 系统
> **I want to** 限制旅行社违规操作
> **So that** 防止倒票、套利行为

**验收标准：**
- [ ] 禁止旅行社单独购买门票（必须组合车辆产品）
- [ ] 限制"门票+车辆"组合产品自行部分退订
- [ ] 支持出票后延迟核销
- [ ] OTA 退票后旅行社复购不享受优惠
- [ ] 支持电子围栏和分销商定位

## P1 — 重要功能

### 游客 (TOURIST)

#### US-010 跨业态组合产品购买
> **As a** 游客
> **I want to** 一键购买"门票+缆车+餐饮"等组合套餐
> **So that** 享受优惠价格，一站式规划行程

**验收标准：**
- [ ] 支持门票+车辆+缆车+酒店+餐饮+文创等跨业态组合
- [ ] 展示组合产品的项目、使用规则、有效期和分项价格
- [ ] 支持购物车统一结算
- [ ] 基于行程推荐二次消费产品

#### US-011 年卡购买与刷脸入园
> **As a** 年卡用户
> **I want to** 购卡后刷脸入园，无需每次出示证件
> **So that** 享受更便捷的入园体验

**验收标准：**
- [ ] 支持身份证购买年卡
- [ ] 外宾可凭护照购买年卡
- [ ] 年卡用户凭人脸识别入园
- [ ] 年卡用户支持预约游览

#### US-012 会员积分与优惠
> **As a** 游客
> **I want to** 消费获得积分、使用优惠券、享受会员折扣
> **So that** 获得实惠并愿意再次消费

**验收标准：**
- [ ] 消费获得积分，积分可兑换商品或抵扣现金
- [ ] 支持签到、互动等非消费方式获取积分
- [ ] 支持优惠券包、生日礼遇、等级特权
- [ ] 积分与酒店、餐饮、文创、停车等业态联动
- [ ] 积分核销率可监测

#### US-013 电子发票申请
> **As a** 游客
> **I want to** 在线申请订单电子发票
> **So that** 无需窗口排队，发票直接发送至邮箱或微信卡包

**验收标准：**
- [ ] 支持填写个人/企业抬头、税号、商品/服务类目
- [ ] 多业态按品类、税号分别开票
- [ ] 查看开票进度
- [ ] 发票通过邮件、微信卡包等方式交付
- [ ] OTA 分销渠道在自营小程序开票

#### US-014 拼团与秒杀
> **As a** 游客
> **I want to** 参与拼团和秒杀活动
> **So that** 享受更优惠的价格

**验收标准：**
- [ ] 支持拼团活动，达到成团人数自动成团
- [ ] 支持秒杀活动，限时限量
- [ ] 未成团自动退款

#### US-015 智慧导览
> **As a** 游客
> **I want to** 在景区内使用手绘地图导航和语音讲解
> **So that** 便捷找到景点和服务设施

**验收标准：**
- [ ] 高精度定制手绘地图
- [ ] 标注景点、卫生间、餐厅、停车场、缆车站
- [ ] 支持语音讲解
- [ ] 支持路线规划
- [ ] 支持一键呼叫客服

#### US-016 AI 问答助手
> **As a** 游客
> **I want to** 通过文字或语音向 AI 助手询问景区相关问题
> **So that** 7x24 小时随时获得帮助

**验收标准：**
- [ ] 嵌入首页、导览页、商品详情页等多场景
- [ ] 支持文字和语音输入
- [ ] 7x24 自动回复
- [ ] 无法回答时自动转接人工客服
- [ ] 响应时间 < 2 秒

#### US-017 租赁服务
> **As a** 游客
> **I want to** 在线租赁讲解器、童车、轮椅等设备
> **So that** 按需使用，便捷归还

**验收标准：**
- [ ] 支持按小时/天计费
- [ ] 支持押金支付和原路径退还
- [ ] 支持在线预约和现场扫码租赁

### 景区运营管理者 (OPS_MANAGER)

#### US-018 经营大屏
> **As a** 景区运营管理者
> **I want to** 在 LED 大屏上实时查看门票、客流、销售额等核心经营数据
> **So that** 实时掌握景区运营状况，快速做出调度决策

**验收标准：**
- [ ] 显示实时售检票数据、各检票点人次、分时检票人次
- [ ] 显示票种排行、线上线下占比、OTA/旅行社排行
- [ ] 显示文创、酒店、餐饮、停车场、商业街、车辆等数据
- [ ] 支持当日客流与历史同期对比
- [ ] 支持近 7 天趋势、近 6 月检票与销售数据
- [ ] 支持游客画像展示：国内外占比、客源地 TOP、性别年龄分析
- [ ] 支持历史数据回溯查询
- [ ] PC 端和手机端双平台管理视图

#### US-019 多维报表
> **As a** 景区运营管理者
> **I want to** 按产品、售票员、渠道、OTA 等维度查看销售和经营报表
> **So that** 精准分析经营状况，优化运营策略

**验收标准：**
- [ ] 支持自定义字段查询与导出
- [ ] 支持游客画像分析：产品偏好、省市来源、国家、年龄、性别、客单价、游玩时长、复游率、提前预约占比
- [ ] 支持销售与核销差异报表
- [ ] 支持退票数量、退票原因、强制退票、换渠道复购专题分析
- [ ] 支持缆车、车辆单双程乘坐统计
- [ ] 支持出入库整月和个人统计导出
- [ ] 支持按模块、部门、岗位、人员维度划分数据权限
- [ ] 支持历史同期对比和异常预警（游客数/销售额大幅下降提醒）
- [ ] 财务报表支持数据透视表式汇总溯源

#### US-020 商品与渠道管理
> **As a** 景区运营管理者
> **I want to** 统一管理多业态商品、组合产品、定价和渠道上下架
> **So that** 灵活响应市场需求，高效运营

**验收标准：**
- [ ] 支持场景管理：日场票、夜场票、多业态组合套票
- [ ] 支持产品类型、名称、价格、复制创建票种
- [ ] 支持 SPU/SKU 批量导入导出、上下架
- [ ] 支持组合产品绑定、自定义总价、分项结算价和清分规则
- [ ] 支持渠道管理：现场窗口、小程序、OTA、旅行社
- [ ] 支持自动上下架时间和批量操作
- [ ] 支持运营规则配置：下单、核销、退改、支付等
- [ ] 支持多业态组合产品价格日历
- [ ] 支持多平台统一发布产品、新闻、公告

#### US-021 系统设置
> **As a** 景区运营管理者
> **I want to** 配置系统的运营参数、消息模板和接口
> **So that** 系统按需运行，灵活适配业务变化

**验收标准：**
- [ ] 设备管理：设备增删改查及图文列表、状态监控
- [ ] 短信、微信、邮件模板管理
- [ ] 接口管理：第三方接口维护，主动和被动对接
- [ ] 消息中心：支持商家提醒、闭园/异常批量通知、外宾批量退票提醒
- [ ] 季节管理、日夜场管理
- [ ] 支付中心配置
- [ ] 预警信息通过微博、微信、LED、PC 官网一键发布

#### US-022 商户与内容管理
> **As a** 景区运营管理者
> **I want to** 管理入驻商户、审核内容和营销活动
> **So that** 保障平台内容质量和商户服务质量

**验收标准：**
- [ ] 商户入驻资质审核、店铺启停
- [ ] 商户商品审核：内容合规、价格合理性
- [ ] 营销规则管理：优惠券、秒杀、拼团、限时折扣、全民分销
- [ ] UGC 内容审核：先审后发或先发后审、加精、置顶
- [ ] AI 知识库管理：FAQ、产品、政策规则维护、对话日志纠错

#### US-023 会员与用户运营
> **As a** 景区运营管理者
> **I want to** 管理会员等级、积分规则和精准营销
> **So that** 提升用户粘性、复购率和客单价

**验收标准：**
- [ ] 会员等级、积分规则、权益配置
- [ ] 用户信息、行为数据、标签体系管理
- [ ] 精准优惠推送、定向发券
- [ ] 转化率、复购率、积分核销率监测
- [ ] 会员消费记录关联、积分明细查询

### 财务人员 (FINANCE)

#### US-024 清分结算
> **As a** 财务人员
> **I want to** 系统自动完成组合票分账和商户收益清分
> **So that** 结算准确高效，减少人工核对工作量

**验收标准：**
- [ ] 组合票订单总金额自动分账，分项清分明细可查
- [ ] 商户收益按佣金比例自动清分
- [ ] 支持自营+商户+OTA+旅行社多来源订单统一结算
- [ ] 支持按核销日期做账
- [ ] 本期支持清分报表手工做账与打款

#### US-025 用友 NC 凭证对接
> **As a** 财务人员
> **I want to** 系统自动生成用友 NC 财务凭证
> **So that** 财务数据自动同步，减少手工录入

**验收标准：**
- [ ] 按预设规则自动生成财务凭证
- [ ] 财务报表支持数据透视表式汇总溯源
- [ ] 凭证数据与订单、支付、清分数据一一对应

#### US-026 发票管理
> **As a** 财务人员
> **I want to** 管理发票申领、开具、冲红和归档全流程
> **So that** 税务合规，开票流程可追溯

**验收标准：**
- [ ] 对接数电票/税控平台
- [ ] 支持发票号段申领、开具、冲红、归档
- [ ] 多业态税目映射
- [ ] 开票申请审核
- [ ] 按品类、税号、订单状态统计开票情况
- [ ] 支持多业态电子发票

**验收标准：**
- [ ] 在线提交资质文件
- [ ] 签署电子合同
- [ ] 多级审批流程
- [ ] 店铺可视化装修
- [ ] 商品上架、价格库存管理

#### US-028 商户订单核销
> **As a** 商户管理员

> **As a** 商户管理员

**验收标准：**
