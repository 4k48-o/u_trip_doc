## 数据库 / 后端

| 术语 | 说明 |
|------|------|
| 主键 (Primary Key) | 表中唯一标识一条记录的字段 |
| 外键 (Foreign Key) | 关联其他表主键的字段 |
| 索引 (Index) | 加速查询的数据结构 |
| 事务 (Transaction) | 一组不可分割的数据库操作 |
| 分页 (Pagination) | 将大量数据分批返回 |
| 幂等 (Idempotent) | 多次执行结果与一次执行相同的操作 |
| 熔断 (Circuit Breaker) | 服务不可用时主动切断请求以保护系统 |
| 降级 (Degradation) | 服务不可用时提供兜底方案 |
| 限流 (Rate Limiting) | 控制单位时间内的请求次数 |

## 前端

| 术语 | 说明 |
|------|------|
| 组件 (Component) | 可复用的 UI 单元 |
| 状态管理 (State Management) | 管理应用全局状态 |
| 路由 (Routing) | URL 到页面/组件的映射 |
| 虚拟 DOM (Virtual DOM) | 内存中的 UI 表示，用于高效更新真实 DOM |
| 响应式设计 (Responsive) | 不同屏幕尺寸的自适应布局 |
| 无障碍访问 (A11y) | Accessibility，确保残障用户可使用 |
