## 8. 对接规范

### 超时与重试

| 配置 | 值 | 说明 |
|------|-----|------|
| 连接超时 | 5s | 建立连接的最长等待时间 |
| 读取超时 | 30s | 等待响应的最长时间 |
| 最大重试次数 | 3 | 失败后重试次数 |
| 重试间隔 | 1s, 2s, 4s | 指数退避 |

### 错误处理

- 所有外部调用必须做 try-catch，避免外部异常导致主流程崩溃
- 关键外部服务不可用时触发降级逻辑
- 错误日志记录完整的请求/响应信息（脱敏后）

### 幂等性

- 支付/扣款等写操作必须支持幂等
- 通过业务唯一键或幂等 Token 实现

## 9. 外部服务依赖状态

| 服务 | 用途 | 依赖等级 | 降级方案 |
|------|------|----------|----------|
| 数据库 | 核心存储 | 关键路径 | 无 |
| Redis | 缓存/会话 | 非关键 | 绕过缓存直查 DB，禁用限频 |
| 短信服务 | 发送验证码 | 非关键 | 提示用户稍后重试 |
| 邮件服务 | 发送通知 | 非关键 | 进入延迟队列重试 |
| OSS | 文件存储 | 关键路径 | 本地存储兜底 |
| 支付 | 收款 | 关键路径 | 无 |
